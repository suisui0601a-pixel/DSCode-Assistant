# DSCode Assistant 开发说明

[English](Development_Guide.md)

## 1. 开发原则

- 本地优先，不建立开发者服务器。
- 不增加账号、遥测或用户行为统计。
- API 密钥只进入操作系统凭据库。
- 保持模块直接、可测试，避免过度抽象。
- 核心业务与 GUI、数据库、网络边界清晰。

## 2. 环境准备

```powershell
python -m venv .venv
.venv\Scripts\activate
python -m pip install --upgrade pip
python -m pip install -r requirements.txt
```

运行：

```powershell
python -m dscode_assistant
```

## 3. 主要模块

| 文件 | 职责 |
| --- | --- |
| `app.py` | QApplication、主窗口和资源释放 |
| `main_window.py` | 主窗口与会话管理 |
| `chat_widget.py` | 聊天交互、消息生命周期和 ChatWorker 连接 |
| `api_client.py` | DeepSeek 官方 API 和流式解析 |
| `model_providers.py` | 模型提供商抽象与 OpenAI 兼容接口适配 |
| `context/` | 确定性上下文准备、Token估算和关键消息保护 |
| `languages/` | 本地语言元数据与语言识别提示 |
| `database.py` | SQLite 初始化和历史记录 |
| `settings.py` | 普通设置、数据目录和系统凭据库 |
| `markdown_renderer.py` | Markdown、高亮与安全过滤 |
| `automation.py` | localhost Automation 接口 |

## 4. 质量检查

```powershell
python -m compileall -q dscode_assistant tests
python -m pytest -q
```

UI 测试可使用无窗口平台：

```powershell
$env:QT_QPA_PLATFORM = "offscreen"
python -m pytest -q
```

## 5. 安全要求

提交前必须检查：

- `.env`、API 密钥、Token、密码和私钥
- `settings.json`、SQLite 数据库和日志
- 本机绝对路径、个人邮箱和未脱敏截图
- `build/`、`dist/`、`release/` 与虚拟环境

测试密钥必须使用明显不可用的占位值，不得调用真实账户。

## 6. 构建 Windows 版本

安装 Inno Setup 6 后运行：

```bat
build_windows.bat
```

脚本会创建隔离构建环境，运行 PyInstaller，并在 `release/` 生成版本化便携包；检测到 Inno Setup 时同时生成安装包。

## 7. 贡献建议

一次提交只处理一项完整功能或明确修复。提交前运行相关测试，不提交生成文件和私人数据。涉及数据库结构、API 调用格式或线程模型的变更应先在 Issue 中说明兼容性影响。
