# DSCode Assistant 用户使用说明

## 1. 启动软件

Windows 用户可运行安装版快捷方式，或在便携目录中运行 `DSCode Assistant.exe`。首次启动会在本机应用数据目录创建普通设置和 SQLite 历史数据库。

## 2. 配置模型

1. 点击左侧栏底部“设置”。
2. 选择 DeepSeek 或 OpenAI Compatible。
3. 填写对应模型、API Key 和参数。
4. 点击“测试连接”。
5. 测试成功后保存。

API Key 输入框使用密码显示模式，保存后由操作系统凭据库管理。

## 3. 创建与使用会话

1. 点击“新建对话”。
2. 从输入区选择编程模板。
3. 输入问题并按 Enter 发送；Shift+Enter 换行。
4. 生成期间可以点击“停止”。
5. 回复完成后，会话保存在本机数据库中。

## 4. 管理历史

- 使用左侧搜索框筛选会话。
- 双击会话或使用菜单重命名。
- 删除会话前软件会要求确认。
- 设置页可以清理全部历史记录。

删除操作不可从软件内恢复，操作前请确认不再需要相关记录。

## 5. 数据位置

Windows 默认目录：

```text
%APPDATA%\DSCodeAssistant
```

该目录通常包含 `settings.json`、`dscode_assistant.db` 和隐私安全诊断日志。API Key 不保存在该目录，而位于系统凭据库。

## 6. 退出软件

关闭主窗口时，软件会停止正在运行的聊天线程、关闭本地数据库和 localhost Automation 接口。若模型请求仍在生成，建议先点击“停止”再退出。
