# Screenshot contribution guide

[简体中文](README.zh-CN.md)

This directory is reserved for privacy-reviewed DSCode Assistant screenshots.

Expected filenames:

- `main-window.png`
- `settings.png`

Before adding a screenshot, confirm that it contains no API key, token, private source code, chat history, personal email address, local user path, database content, or other identifying information. Use a clean test profile and placeholder conversations.

The repository intentionally does not include unreviewed screenshots.
