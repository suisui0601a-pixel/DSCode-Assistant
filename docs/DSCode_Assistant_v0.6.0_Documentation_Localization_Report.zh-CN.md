# DSCode Assistant v0.6.0 文档双语整理报告

[English](DSCode_Assistant_v0.6.0_Documentation_Localization_Report.md)

## 1. 整理范围

本次任务面向国际 GitHub 用户和简体中文用户整理 v0.6.0 公开文档。英文作为仓库默认展示语言，中文文档作为完整参考版本，不采用逐句机器直译。

双语整理阶段没有修改应用源码、数据库结构、模型提供商请求行为或版本号。

## 2. 英文文档优化

- 保持 `README.md` 为 GitHub 默认入口，并直接说明项目的本地优先开源定位。
- 使用符合开源项目习惯的表达介绍功能、架构、模型提供商、上下文优化、隐私、安装、配置和开发流程。
- 新增 API 配置、日常使用、开发、Windows 构建和常见问题英文文档。
- 每份英文文档均提供简体中文入口。
- 只描述 v0.6.0 真实代码能力，并明确 Auto 是当前按 Raw 运行的实验占位。

## 3. 中文文档同步

- `README.zh-CN.md` 与英文 README 保持功能和隐私边界一致。
- 补齐中文变更记录、贡献指南、行为准则、Windows 指南和公开发布报告。
- 保留现有中文指南，并为其增加英文对应入口。
- 使用自然中文技术表达，避免逐字翻译。

类名、代码标识符、API 路径、文件名和必须保持一致的界面选项继续使用原始拼写。

## 5. 技术描述一致性

- Raw 保持消息顺序和正文不变。
- Light 执行确定性清理和连续短消息有限合并，同时保护关键上下文。
- Auto 是已保存的实验选项，当前按 Raw 运行。
- 软件显示的 Token 数是本地估算，不是模型提供商账单数据。
- API 密钥保存在操作系统凭据库。
- 会话历史保存在本地 SQLite 数据库。
- 项目没有强制账号、遥测或 DSCode 运营的中转服务器。
