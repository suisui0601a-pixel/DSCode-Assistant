# DSCode Assistant 常见问题

[English](FAQ.md)

## 软件会上传我的全部代码吗？

不会自动扫描或上传项目目录。只有你主动输入或粘贴到当前会话并发送的内容，以及该会话需要携带的历史上下文，会提交给所选模型服务。

## API 密钥保存在哪里？

保存在操作系统凭据库，不写入普通 JSON、SQLite 或日志。

## 聊天记录保存在哪里？

保存在本机应用数据目录中的 SQLite 数据库。DSCode Assistant 没有开发者云端数据库。

## 为什么使用 API 会产生费用？

DSCode Assistant 免费开源，但模型 API 由服务提供商计费。费用、额度和价格以模型服务账户为准。

## Light 上下文优化会改写代码吗？

不会。Light 只进行确定性清理和有限的短消息合并，并保护代码块、补丁、错误日志、约束和文件引用。它不会调用额外模型，也不会对代码进行语义摘要。显示的 Token 数是本地估算，不是服务商账单。

## 可以使用本地模型吗？

可以连接提供 OpenAI 兼容接口的本地服务。项目当前不负责下载模型、管理模型文件或调度 GPU。

## Automation 接口会自动执行任务吗？

不会。它只在本机 `127.0.0.1` 上激活应用、选择项目和预填任务草稿。用户仍需确认并手动发送。

## 为什么便携版不能只复制 EXE？

PyInstaller onedir 包依赖同目录下的 `_internal` 文件。请完整解压并保留目录结构。

## 如何彻底删除本地数据？

先在设置页清理历史并删除 API 密钥，然后卸载应用，最后按需删除 `%APPDATA%\DSCodeAssistant`。操作前请备份需要保留的会话。

## 如何报告问题？

请在 GitHub Issue 中提供软件版本、操作系统、复现步骤和已脱敏的错误信息。不要上传 API 密钥、私人代码、数据库或包含隐私的截图。
